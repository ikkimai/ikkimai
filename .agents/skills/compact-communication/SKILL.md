# Compact Communication

## Rules
1. Use concise plans.
2. Do not restate the user's request.
3. Do not narrate every shell/search action.
4. Do not paste large unchanged code blocks.
5. When showing code, show only the relevant section unless the full file is requested.
6. Summarize completed work in bullets.
7. Mention validation commands and results briefly.
8. Avoid repeating architecture explanations already established in the conversation.

## Implementation priority
Code correctness > explanation length.
